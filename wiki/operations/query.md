# Query Workflow

## Purpose

Answer questions using the compiled wiki first. File reusable answers back into the wiki so explorations compound.

## Steps

1. Start from [index.md](../index.md).
2. Follow links to relevant concept, entity, decision, and operation pages.
3. Check citations when claims matter.
4. Read raw sources in `sources/raw/` and source notes in `sources/notes/` only when the wiki is missing, stale, or conflicted.
5. Answer concisely with links to wiki pages and source notes.
6. If the answer is reusable — a comparison, analysis, or decision rationale — create or update a wiki page. Prefer updating an existing entity or decision page over creating an orphan answer page.
7. If the answer reveals a wiki gap, update the wiki or record an open question.
8. Append a query entry to [log.md](../log.md) when the answer produces wiki changes.

## Answer Shape

Good answers should include:

- The direct answer.
- The relevant wiki page or source note.
- Any uncertainty or conflict.
- A wiki update when the answer uncovered missing or reusable knowledge.
