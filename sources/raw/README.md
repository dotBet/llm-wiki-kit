# Raw Sources

Immutable originals: PDFs, clipped articles, transcripts, and metadata wrappers for external URLs. These files are the capture layer, not the synthesized wiki.

Rules:

- Do not edit content after capture. Add a new dated file if the source changes.
- Link every raw file from a source note in `../notes/`.
- Download images to `../assets/` when local copies are needed.
- For URL wrappers, record the canonical URL, raw URL when available, repository or document revision, and capture date.
- Keep pinned revisions stable. If the upstream source changes, add a new dated wrapper instead of changing the existing one.
- Use source notes to translate raw material into OKF-compatible wiki provenance; do not put synthesized claims directly into `sources/raw/`.
